# Synthetic Refractory Mechanism Protocol V1

[Done] This small study was preregistered before any arm's development accuracy was measured. The [canonical protocol](../data/processed/benchmark_fixtures/cartpole_refractory_mechanism_v1.json) is SHA-256 `52aeb63b2cc18ef99891cb868ff00a78f7fa2e22db688347c9d12a3e74f94b8d`; the [generator and local learner](../src/sara_engine/evaluation/cartpole_refractory_mechanism.py) are SHA-256 `7969f39c0f5e5a5f7a36eec301091198f0eb414430b123e0be5c6ccc13e80562`; the [one-shot runner](../src/sara_engine/evaluation/cartpole_refractory_runner.py) is SHA-256 `4baa8e814dd36487f8ca99a244adf4c745bd41610c0489104b40f63f646cf849`. The protocol also pins the existing neuron and event types. No real CartPole environment or held-out split is involved. The subsequent [development result](CARTPOLE_REFRACTORY_MECHANISM_RESULT.md) passed this narrow gate.

Five seeds each generate 64 training and 32 development episodes. Every episode has two pulses on one base route, separated by either one or three ticks, plus one irrelevant nuisance-route event. The target is near versus far gap. Base route, start time, nuisance route, label, and a label-blind mask bit are balanced within each seed. Training and development use disjoint absolute-time ranges and nuisance routes; episode identities and exact event patterns do not overlap. The underlying near/far rule is shared by design, so this is a narrow mechanism positive control, not new-family transfer.

All six arms receive the same three events and terminal label, use one of two bounded local features, and train the same flat four-weight mistake-driven learner without global gradients. Development does not update. `scalar_count` sees two raw base events regardless of gap. `compact_gap` uses the explicit time difference. `spiking_refractory` counts spikes from the current 1.6-input neuron. `refractory_disabled` clears its refractory counter; `timing_removed` changes the second pulse to a three-tick gap for both labels. `rate_matched_mask` drops the second pulse on every other episode by a label-independent index bit, preserving the spiking arm's aggregate one-feature/two-feature counts but not their causal alignment with the target. No arm receives the target during feature extraction.

The frozen development gate requires compact and spiking accuracy ≥0.90, spiking accuracy ≥0.875 on every seed, their aggregate gap ≤0.10, each negative control accuracy ≤0.60, spiking minus the rate-matched mask/refractory-disabled/timing-removed controls ≥0.35 each, exactly 16 one-feature episodes per seed for both spiking and rate-matched mask, and bounded local updates/weights. A failure is retained without retuning. The only result location is `workspace/evaluation/cartpole_refractory_mechanism_v1.json`, reserved exclusively before scoring. The study has no held-out partition and cannot authorize any CartPole V2 retune or held-out opening. Even a positive synthetic result would show only that refractory suppression can encode this deliberately gap-identifiable pattern; the compact non-spiking timing arm is an equally informed control.
