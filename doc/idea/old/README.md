# Old Idea Notes

This directory stores documents that were useful during development but are no longer part of the active documentation path.

Keep files here when they still provide historical context or research value, but active commands, release procedures, and current policy should live in `doc/TOOLS.md`, `doc/RELEASE_CHECKLIST.md`, `doc/ROADMAP.md`, and `doc/policy.md`.

Generated comparison images, superseded diagrams, and no-longer-referenced visual drafts should also be moved here so `doc/idea/` stays focused on the current active research notes.
